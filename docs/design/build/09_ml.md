## 0. Non-negotiables this layer inherits (read first)

1. **No lookahead.** Every feature row at decision bar `t` (epoch-ms `ts_open`,
   value available at `ts_open + Δ`) is produced by the ONE feature framework
   (`features/engine.py`, the same `compute_history`/`compute_asof` the live
   loop runs). The meta-model NEVER recomputes features; it consumes the
   engine's `(ts_open, instrument_id)` MultiIndex frame verbatim. The label's
   `t1` (event end) is purged against by `PurgedWalkForward` /
   `CombinatorialPurgedCV` (`validation/splits.py`, `validation/cpcv.py`) — the
   ONE splitter library (finding 16). Phase 9 imports it; it does not fork it.
2. **Cost-honest label (finding 11).** The model trains on the meta-label
   `y_meta ∈ {0,1}` from the triple-barrier layer, where `y_meta = 1{s·ret_net > 0}`
   and `ret_net` is NET of fees + half-spread + expected funding over the hold
   (the `09_labeling` build doc). Phase 9 treats the label as an input contract;
   it asserts the label frame carries the `net` provenance flag and refuses a
   gross-only label frame for a production fit (gross label allowed only when
   `cfg.allow_gross_label=True`, a diagnostic path).
3. **Gate, never flip (finding 12 / §5.3).** The model emits a calibrated
   `p = P(y_meta = 1 | X) ∈ [0,1]`. Bet size is `size = s·(2Φ(z)−1)` with
   `z = (p−0.5)/√(p(1−p))`, floored to `0` when `p < p_min`. `size` SHARES the
   sign of `s = sign(Ã)` by construction; `|size| ∈ [0,1]` scales the blend
   `F = size·|Ã|`. The model output multiplies the magnitude only — there is no
   code path in which `p` changes the sign of `Ã`. A unit test asserts
   `sign(F) == sign(Ã)` for all finite rows (or `F == 0`).
4. **Calibration split is disjoint from early-stopping (finding 9).** The
   trailing validation tail is split **40d early-stop / 20d isotonic**: the
   GBM's iteration count is chosen on the 40d block, the `IsotonicRegression`
   map is fit on the disjoint 20d block, and neither is reused for
   champion/challenger promotion. Promotion is judged ONLY on data strictly
   after BOTH the champion's and the challenger's fit+calibration windows
   (§4 below). One 60d tail is never triple-used.
5. **No LightGBM on this machine.** Model = sklearn
   `HistGradientBoostingClassifier` behind a `ModelProtocol` seam so LightGBM
   swaps in later with zero call-site changes (§1). HMM is hand-rolled
   (Phase 11). Optimizer stays cvxpy-base + Clarabel (Phase 12, untouched here).

### 1.1 `ml/model.py` — the model + the seam

The seam isolates "a thing that fits weighted binary samples and predicts a
calibrated win-probability" from its implementation. `HistGBMMetaModel` is the
v1 impl; `LightGBMMetaModel` can be added later implementing the same Protocol.

```python
# Constants (module level, Final)
DEFAULT_PARAMS: Final[Mapping[str, object]] = {
    "max_depth": 4,                 # shallow: up to 4-way interactions, all S/N supports
    "learning_rate": 0.03,          # slow; iteration count chosen by early stopping
    "max_iter": 2000,               # ceiling; early_stopping picks the real number
    "min_samples_leaf": 200,        # every leaf is a >=200-sample statistical statement
    "l2_regularization": 5.0,       # heavy L2 shrink of leaf values toward 0
    "max_bins": 127,                # coarse bins resist micro-noise splits
    "early_stopping": True,
    "n_iter_no_change": 50,
    "random_state": 42,
    # NOTE: validation_fraction is NOT used — we pass an explicit purged tail
    # via `validation_data` so early stopping never leaks across the t1 gap.
}
EARLY_STOP_DAYS: Final[int] = 40        # finding 9: ES block
ISOTONIC_DAYS: Final[int] = 20          # finding 9: calibration block (disjoint)
P_MIN: Final[float] = 0.50              # never trade against the classifier (§5.3)
SIZE_STEP: Final[float] = 0.05          # discretize bet size to suppress churn


@runtime_checkable
class ModelProtocol(Protocol):
    """The seam: a weighted binary classifier emitting calibrated P(win).

    Implementations are pure of global state, deterministic given `random_state`,
    and NEVER read features they were not handed (no lookahead by construction —
    X arrives from the ONE feature engine). `feature_names` pins column order so
    serve-time X is realigned, not positionally assumed.
    """
    @property
    def feature_names(self) -> tuple[str, ...]: ...
    def predict_proba(self, X: pd.DataFrame) -> np.ndarray: ...   # shape (n,), calibrated p in [0,1]
    def save(self, path: Path) -> None: ...
    @classmethod
    def load(cls, path: Path) -> Self: ...


@dataclass(frozen=True, slots=True, kw_only=True)
class FitWindows:
    """The three disjoint time spans of one fit (finding 9), in epoch-ms UTC.

    train: [train_start, es_start)        # GBM trees fit here
    early_stop: [es_start, iso_start)     # 40d; chooses n_iter, purged from train by t1
    isotonic:  [iso_start, fit_end)       # 20d; fits the isotonic map, disjoint from ES
    `fit_end` is the last decision-bar t whose label t1 <= asof (fully realized).
    """
    train_start: Ms
    es_start: Ms
    iso_start: Ms
    fit_end: Ms


class HistGBMMetaModel:
    """sklearn HistGradientBoostingClassifier + isotonic calibration (ModelProtocol).

    fit() pipeline (alphaDesign §6.2, findings 9/11):
      1. Align X to `feature_names`; assert no NaN target/weight; assert the label
         frame is cost-honest (`ret_net`) unless cfg.allow_gross_label.
      2. PURGE: drop train rows whose label interval [t, t1] overlaps the
         early-stop block — reuse PurgedWalkForward's purge arithmetic, NOT a
         re-implementation (finding 16). The ES block is the held tail, not a
         random sklearn validation_fraction.
      3. Fit HistGradientBoostingClassifier(**DEFAULT_PARAMS) with sample_weight,
         early stopping on the purged 40d ES block (binary log loss).
      4. Fit IsotonicRegression(out_of_bounds="clip") mapping raw GBM scores ->
         empirical P(win) on the DISJOINT 20d isotonic block.
      5. Freeze. predict_proba returns isotonic(raw_score).
    """
    def __init__(self, *, params: Mapping[str, object] | None = None,
                 random_state: int = 42) -> None: ...
    def fit(self, X: pd.DataFrame, y: pd.Series, w: pd.Series, t1: pd.Series,
            windows: FitWindows, *, label_is_net: bool = True) -> Self: ...
    @property
    def feature_names(self) -> tuple[str, ...]: ...
    def predict_proba(self, X: pd.DataFrame) -> np.ndarray: ...
    def save(self, path: Path) -> None: ...       # joblib: estimator + calibrator + feature_names + sha
    @classmethod
    def load(cls, path: Path) -> Self: ...


def bet_size_from_prob(p: pd.Series, side: pd.Series, *,
                       p_min: float = P_MIN, step: float = SIZE_STEP) -> pd.Series:
    """LdP bet size (§5.3): side·(2Φ((p-.5)/√(p(1-p)))-1), floored at p_min,
    discretized to `step`. sign(out) == sign(side) or out == 0 — NEVER flips
    (finding 12). p outside (0,1) -> 0 (degenerate). Returns Series in [-1, 1]."""
```

`feature_names` is the enumerated decision-time matrix (§3). `t1` is the label
event-end column from the labeling layer (already a contract field). The fit
is pure given inputs + `random_state`; `HistGradientBoostingClassifier` is
deterministic for a fixed seed and single-threaded sklearn build on arm64.

### 1.2 `ml/importance.py` — MDA permutation importance

```python
def cluster_features(X: pd.DataFrame, *, corr_threshold: float = 0.7) -> dict[str, list[str]]:
    """Hierarchical clustering (average linkage) on d = 1 - |ρ_Spearman|, cut so
    |ρ| >= corr_threshold => same cluster (§6.3). Kills the substitution effect
    that makes per-feature permutation lie about correlated factors. Deterministic
    cluster ids 'cluster_00', 'cluster_01', ... by ascending member-min index."""

def mda_importance(model_factory: Callable[[], HistGBMMetaModel],
                   X: pd.DataFrame, y: pd.Series, w: pd.Series, t1: pd.Series,
                   splitter: PurgedWalkForward, clusters: Mapping[str, list[str]],
                   *, n_repeats: int = 5, seed: int = 42) -> pd.DataFrame:
    """Cluster-permutation MDA over purged WF folds (§6.3):
      for each (train, test) from splitter.split(grid):
        fit a fresh model on train; base = logloss(model, test X, y, w)
        for each cluster G, for r in range(n_repeats):
          permute ALL columns of G JOINTLY (same row permutation per column)
          within the TEST fold only, recompute logloss
          imp_fold[G] += (logloss_permuted - logloss_base)
    Returns frame index=cluster id, cols [mean, std, members]; a cluster whose
    mean - std <= 0 is a removal candidate. Permutation RNG seeded per (fold,
    cluster, repeat) so the report is reproducible. Importance is on the held
    test fold (OOS), never on train — train MDA is meaningless on a fit set.
    The splitter is the SAME PurgedWalkForward; no re-implemented folds."""
```

No SHAP in Phase 9 (the design's SHAP step assumed LightGBM's `TreeExplainer`;
sklearn-Hist-GBM SHAP is deferred — MDA is the gate-relevant signal and is
model-agnostic across the seam).

### 1.4 `ml/retrain.py` — weekly retrain + promotion

```python
@dataclass(frozen=True, slots=True, kw_only=True)
class PromotionVerdict:
    """The judged comparison (finding 9): metrics on the OOS window strictly
    after BOTH models' fit+calibration windows. `oos_start` = max(champion.fit_end,
    challenger.fit_end) + embargo; promote iff the gate below passes."""
    promote: bool
    oos_start: Ms
    oos_end: Ms
    n_oos: int
    challenger_logloss: float
    champion_logloss: float | None
    challenger_rank_ic: float
    champion_rank_ic: float | None
    reason: str


def build_fit_windows(asof: Ms, *, window_days: int = 365,
                      es_days: int = EARLY_STOP_DAYS,
                      iso_days: int = ISOTONIC_DAYS,
                      horizon_bars: int) -> FitWindows:
    """Carve [asof - 365d ... asof] into train / 40d ES / 20d isotonic, with
    fit_end = last t whose t1 (= t + horizon_bars·Δ) <= asof (fully realized).
    horizon_bars is THE single shared constant (SignalsCfg.horizon_bars)."""

def weekly_retrain(asof: Ms, *, registry: ModelRegistry, dataset: MLDataset,
                   settings: Settings, code_git_sha: str,
                   window_days: int = 365) -> tuple[ModelCard, PromotionVerdict]:
    """Sundays 00:30 UTC (after the 00:00 bar). Steps:
      1. windows = build_fit_windows(asof, horizon_bars=settings.signals.horizon_bars)
      2. fit challenger HistGBMMetaModel on the 365d window (purged ES, disjoint isotonic)
      3. champion = registry.champion()  (None on cold start -> auto-promote candidate)
      4. verdict = judge_promotion(challenger, champion, dataset, settings, asof)
      5. registry.register(card, challenger, importance); if verdict.promote:
         registry.promote(card.model_id)  else: keep champion, log alert
    Returns (challenger card, verdict). Pure of clock — asof passed in."""

def judge_promotion(challenger: HistGBMMetaModel, champion_card: ModelCard | None,
                    dataset: MLDataset, settings: Settings, asof: Ms) -> PromotionVerdict:
    """Promotion gate, judged ONLY on data after BOTH fit windows (finding 9):
      oos_start = (champion_card.fit_end if champion else challenger.windows.fit_end)
                  ... in fact max of both, + embargo_bars
      Cold start (champion is None): promote=True, reason='cold-start'.
      Else promote iff:
        logloss_new  <= logloss_champ + 0.002   AND
        rank_ic_new  >= 0.8 * rank_ic_champ
      on the shared OOS window [oos_start, asof realized]. If that window has
      < min_oos samples -> promote=False, reason='insufficient-oos' (do NOT fall
      back to a contaminated tail — finding 9). rank_ic via validation.metrics.rank_ic
      on the meta-prob vs the §5.1 forward return, non-overlapping h-grid."""
```

`MLDataset` (the X/y/w/t1/side aligner) is assumed delivered by `ml/datasets.py`
(design §1, built alongside but its full spec is its own build doc); Phase 9
consumes it as `dataset.matrices(start, end) -> (X, y, w, t1, side)` with the

## 2. The promotion-window correctness argument (finding 9, expanded)

The original design triple-used one 60d tail (early-stop + isotonic + promotion)
and the incumbent had already consumed ~53 of those days. This layer breaks all
three uses apart:

| use | window | who fits/selects on it |
|---|---|---|
| iteration count (early stop) | 40d ES block | challenger GBM only |
| calibration map | 20d isotonic block (disjoint) | challenger isotonic only |
| **promotion decision** | OOS window AFTER `max(champ.fit_end, chall.fit_end) + embargo` | neither model's fit touched it |

Because both `fit_end`s are recorded on the `ModelCard`, `judge_promotion`
computes `oos_start` from data, not a fixed 60d offset. With weekly retrains the
honest OOS window is the live week(s) since the champion trained — genuinely
out-of-sample for both. If that window is too short, the verdict is
`insufficient-oos` and the champion stays; it NEVER borrows from a fit block.
Each promotion decision is a trial; `retrain.py` appends its config hash to the
`ExperimentLog` (`validation/experiments.py`) so the DSR `N` counts it
(finding 10 discipline).

## 3. Feature matrix available at decision time (enumerated)

The model consumes the engine's processed `(ts_open, instrument_id)` frame. From
`src/alphaforge/features/library/` (registered specs) the decision-time columns
are:

- Momentum / reversal / carry / beta directional alphas (these also drive the
  blend side `s`): `mom_xs_*`, `mom_ts_*` (momentum.py / momentum_slow.py),
  `mr_res_*` (mean_reversion.py), `carry_z_252`, `carry_mom_21_63` (carry.py /
  carry_dynamics.py), `beta_lowbeta_720` (market_state.py). `cross_sectional=True`
  ones arrive POST-CSPipeline (winsorize→zscore, PIT-masked), `direction`-signed.
- Risk / regime context (`direction=0`, fed raw): `vol_yz_168`, `vol_yz_720`,
  `vol_pk_168`, `vol_ratio_168_720`, `lowvol_720`, `semivar_skew_504`
  (vol.py / vol_premium.py), `liq_amihud_720`, `liq_volz_720`,
  `liq_volz_24h_sum`, `liq_cs_spread_168`, `adv_quote_30d` (liquidity.py),
  `reg_rvp_720`, `reg_corr_btc_720`, `reg_breadth_sma720`, `reg_breadth_mom168`
  (regime_features.py), `sigma_daily` (market.py).

The model feature set is `direction != 0` alphas (signed) ∪ `direction == 0`
risk/regime context — the meta-model learns *when the side works given the
regime*, exactly the §6.1 factorization. `feature_names` on the `ModelCard` pins
the exact set + order for the fit, and serve-time X is realigned to it (column
drift between train and serve is a loud `KeyError`, never a silent positional
mismatch). The model does NOT see the raw forward return, `t1`, `side`, or any
post-decision quantity (asserted in fit: the feature set ∩ {label columns} = ∅).

## 4. Unit tests (`tests/unit/`, flat, matching `test_dsr.py` / `test_signal_service.py`)

`test_ml_model.py`
- `test_default_params_shallow_regularized`: asserts the four pinned knobs
  (max_depth=4, learning_rate=0.03, min_samples_leaf=200, l2_regularization=5).
- `test_fit_uses_disjoint_es_and_isotonic_blocks`: build a synthetic dataset with
  a known structure; assert the ES block and isotonic block do not overlap and
  that no isotonic-block row is in the GBM's `_fit_X` (probe via the carved
  windows). Finding 9.
- `test_no_lookahead_es_block_purged`: a train row whose `[t, t1]` overlaps the
  ES block must be absent from the trees' training set; reuse PurgedWalkForward
  arithmetic and assert no purged index leaks.
- `test_calibrated_proba_in_unit_interval_and_monotone`: `predict_proba ∈ [0,1]`;
  isotonic output is non-decreasing in the raw score (sort + `np.diff >= -eps`).
- `test_predict_realigns_columns`: feed X with shuffled / extra columns ->
  realigned to `feature_names`; a missing required column raises `KeyError`.
- `test_save_load_roundtrip_identical_proba`: `load(save(m))` gives bitwise-equal
  `predict_proba` on a fixed X; `data_sha256`/`feature_names` survive.
- `test_feature_set_disjoint_from_labels`: fit raises if X contains `fwd_ret_*`,
  `t1`, `side`, or `meta_label`.

`test_ml_bet_size.py` (gate-never-flip, finding 12)
- `test_size_shares_side_sign`: for random `p ∈ (0,1)`, `side ∈ {−1,+1}`,
  `sign(bet_size_from_prob) == side` wherever non-zero; assert F = size·|Ã|
  never flips `sign(Ã)`.
- `test_size_zero_below_pmin`: `p < 0.5 -> size == 0` (never trade against).
- `test_size_discretized_and_bounded`: output is a multiple of `step` and in
  `[-1, 1]`; `p=0.5 -> 0`; `p->1 -> |size|->1`.
- `test_degenerate_p_zero`: `p in {0,1}` and NaN -> size 0 (no div-by-zero).

`test_ml_importance.py`
- `test_clusters_collapse_correlated_pair`: two columns with |ρ|=0.95 land in one
  cluster; an independent column is its own cluster. Deterministic cluster ids.
- `test_mda_positive_for_informative_cluster`: synthetic label = function of one
  cluster + noise; that cluster's MDA mean > 0 and `mean − std > 0`; a pure-noise
  cluster's CI includes 0.
- `test_mda_uses_purged_folds`: monkeypatch/spy the splitter to assert MDA calls
  `PurgedWalkForward.split` and never an unpurged loop; importance computed on
  test folds only.
- `test_mda_reproducible`: same seed -> identical frame.

`test_ml_registry.py`
- `test_register_then_champion_roundtrip`: register a card+model, `load_champion`
  returns an equivalent model (equal proba on fixed X).
- `test_single_champion_invariant`: promoting B retires A; exactly one champion.
- `test_artifacts_written`: `model.joblib`, `card.json`, `mda_importance.parquet`
  exist under `artifacts/<model_id>/`; `data_sha256` matches the source parquet.
- `test_history_newest_first` and `test_unknown_model_id_raises`.

`test_ml_retrain.py`
- `test_promotion_window_after_both_fit_ends`: construct champion with
  `fit_end = T0` and challenger with `fit_end = T1 > T0`; assert
  `verdict.oos_start == max(T0, T1) + embargo` and that the judged returns use
  only `ts_open >= oos_start`. Finding 9 — the load-bearing test.
- `test_cold_start_auto_promotes`: no champion -> `promote=True`,
  `reason == 'cold-start'`.
- `test_promote_only_if_both_metrics_pass`: challenger better logloss but
  rank_ic < 0.8×champ -> `promote=False`; both pass -> True.
- `test_insufficient_oos_keeps_champion`: short OOS window ->
  `reason == 'insufficient-oos'`, no fallback to a fit block (asserts the judged
  index never enters either model's train/ES/isotonic span).
- `test_retrain_logs_trial_to_experiment_log`: each `weekly_retrain` appends one
  (idempotent) config hash to the `ExperimentLog`.
- `test_build_fit_windows_realized_only`: `fit_end + horizon_bars·Δ <= asof`
  (no unrealized label in the fit).

Golden/property where natural: a synthetic OHLC path with a constructed
edge (one regime where the side wins, one where it loses) should yield a
calibrated `p` that is higher in the winning regime — a behavioural sanity test,
not a tolerance test. No network, no real data; all fixtures synthetic and
seeded, matching the repo's existing unit-test discipline.
