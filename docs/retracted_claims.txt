# RETRACTED CLAIMS — the blocklist that makes a retraction stick.
#
# WHY THIS FILE EXISTS. On 2026-08-06 the signed chain formally withdrew AlphaTrend's DSR of 0.83,
# in entry [24], with the words "was wrong when we wrote it and has been wrong every day since".
# Six days later the number was still on the homepage, still in the /progress social-unfurl card
# that people see WITHOUT opening the site, and still asserted as fact in three glass-box JSON
# artifacts. The retraction had updated the log and nothing else. The site was simultaneously
# publishing the correction and the thing it corrected, from the same pipeline, in the same run.
#
# That is the second time: transparency [21] records the social card advertising a forward Sharpe
# we had stopped believing weeks earlier. A retraction that only appends to the log is not a
# retraction, it is a footnote. So: WITHDRAWING A CLAIM MEANS ADDING A LINE HERE IN THE SAME
# COMMIT. Nothing enforces that but this comment and the fact that the check runs before deploy.
#
# FORMAT — three required "::"-separated fields and one optional fourth field (NOT "|": the
# patterns themselves contain alternation,
# and splitting on "|" tore this file's own regexes in half the first time):
#   <seq> :: <regex that must not be ASSERTED> :: <retraction regex> :: <local non-claim regex>
#
# The third field is what keeps this honest rather than merely silencing. A retracted number MUST
# still be quotable inside its own retraction — deleting the history would be its own dishonesty.
# So a match is a violation ONLY when the exemption pattern is absent from the surrounding window.
# That means the check cannot be satisfied by hiding the number; it is satisfied by explaining it.
# The optional fourth field is narrower. It may excuse only an unambiguous local metric assignment
# that happens to share the digits, never a whole file or a nearby assertion.
#
# A blank exemption field means the claim may not appear at all, in any context.

# 2026-08-18 — THE GATE WAS CRYING WOLF, AND BECAUSE IT ONLY WARNS, NOBODY HEARD IT.
# A run of check_retracted_claims.py found 4 "violations", and all 4 were the CORRECTIONS
# themselves quoting the claim they withdraw — precisely the usage the third field exists to
# permit. The exemption alternations simply did not contain this project's own retraction
# vocabulary: the record says "CORRECTION 2026-08-06 —" and "the sleeve we called '...'", while
# the rules listed only "called it" and "previously". So the honesty gate had been failing on its
# own honesty, every run, into a log read by nobody, which is the same as no gate at all.
#
# Widening an exemption is the one edit this file warns against, so, stated exactly: the terms
# added below are CORRECTION, correcting, we call and we called. Each is an unambiguous marker
# that the surrounding text is a retraction — a passage containing "CORRECTION 2026-08-06" is
# definitionally a correction. No pattern in the SECOND field was touched; nothing that was
# blocked before is permitted now except where a correction is present in the same window.
# The rule was not weakened. The rule was taught the words we actually use to retract.
