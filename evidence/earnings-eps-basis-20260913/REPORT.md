All sample sharefactor fields are 1.0: do not use that column as a universal cumulative split undo factor. This diagnostic establishes that retained EPS is not uniformly the literal EPS number originally published. It does not prove that every normalized EPS-change statistic has lookahead: a common scaling can cancel algebraically, but rounding and consistent adjustment of every denominator still matter. No EPS trading signal or return was computed.

Decision before any performance inspection: use aggregate netinccmn and assets as the input basis for the first seasonal earnings-change candidate. This is a declared accounting-change hypothesis, not analyst-surprise or exact PEAD replication. Formula, normalization, holding schedule and full return preregistration remain to be fixed after pairing coverage and prior-trial identity review. Aggregate accounting vintage, currency and consolidation comparability still need coverage checks; avoiding per-share fields does not certify those.

Implemented isolated scripts/earnings_filing_inputs.py: exact raw-ticker mapping to supplied stable security ID, ARQ only, raw fiscal labels, finite common income/positive assets, and reportperiod<=filing date. Modeled availability is midnight New York two calendar dates after filing (one full intervening day), converted to UTC; actual historical delivery is not claimed. Caller must execute only at a subsequent valid tradable session and enforce endpoint/universe eligibility. No historical lake/loader modification.

The pairing function selects only available observations, latest fiscal quarter and prior fiscal year's same quarter, and latest known version per period. Missing quarters, conflicting same-day versions, different periods with the same fiscal label, and calendar shifts outside 330–400 days return no pair. This helper computes no score. Ten focused tests pass, covering fiscal versus calendar quarters, literal NA ticker, summer/winter timing, future filings/revisions, duplicate/missing/ambiguous periods, invalid values, security isolation and naive timestamps.
