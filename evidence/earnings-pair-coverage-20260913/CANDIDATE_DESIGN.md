# Filing-known seasonal common-income change: fixed candidate design

Status: formula and economic design fixed before historical score computation; execution implementation/specification and trial reservation still required. This is not a completed return preregistration.

Hypothesis: investors incompletely incorporate persistent changes in quarterly common income after the regulatory filing. Use (current quarterly netinccmn - prior fiscal year's same-quarter netinccmn) / prior same-quarter assets. Higher is better. No EPS, analyst-estimate surprise, TTM level, profitability composite, learned weights, clipping search or sign inversion. The common-income change normalized by assets is dimensionless when currency is consistent. The denominator is the prior pair's assets, not the current assets; positive assets required.

Input selection uses the isolated filing helper's backward-known fiscal pairs, availability at filingdate+2 midnight New York, a maximum 180-day age since modeled availability, unambiguous stable ID, and frozen membership. Only current USD metadata and both pair fxusd exactly1 are candidates; this is a currency consistency screen, not historical currency or consolidation certification. Missing or invalid observations are excluded; older valid observations can remain until the freshness cutoff. Any latest-quarter invalid-observation policy changes must be explicit before returns. Do not reinterpret four sequential filings as four quarters.

Initial portfolio design: one monthly rebalance. At the close of the last XNYS session of the preceding month compute ranks using only then-known filings; execute at the following month's first XNYS session raw open. Top20 names long and bottom20 short, equal notional per selected name (2.5% standalone NAV), with at least40 eligible names and no overlapping sides; lexicographic stable security ID resolves ties. Exclude shorts when borrowing is disallowed; costs, borrow, actions, raw-open timing and terminal exits must use the corrected research engine and frozen input bindings. Risk clipping, insufficient liquidity, fewer eligible names and closed-market handling must be specified in the executable protocol, not guessed inside replay. No sector-neutrality claim. Existing sleeve residual/correlation and factor-attribution checks remain admission requirements.
