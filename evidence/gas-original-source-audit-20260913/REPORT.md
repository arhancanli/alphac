# Natural gas alternate original-source audit

The retained EIA original_data workbook covers469weeks in2017–2025. Every one of93 retained archive captures(84uniqueweeks) matches its current-week original Lower48 stock value. However, one archived prior-week value differs from that prior week's original estimate. For2018-06-22 the archived report gives a66Bcf net change; naive successive original stocks give70Bcf. Both stock columns must be from the same report vintage to reconstruct its published weekly change. The original stock panel alone is not equivalent to the original net-change signal.

The workbook has week-ending, source, regional stocks, total stocks and explanation columns, but no report-release timestamps. Matching84weeks does not verify historical availability over469weeks. The earlier17.91%Wayback coverage failure remains unchanged. No market records or returns were opened; union273 unchanged.

EIA's official revision policy says the historical database contains current estimates and that the revisions/reclassifications file preserves original estimates and accompanying notes. The policy also allows unscheduled revisions, so a universal release-time assumption cannot be called measured availability. Source checked September13: https://ir.eia.gov/ngs/revisions.html . This supports the distinction between original values and release lineage; it does not certify the full workbook as a vintage-complete net-change dataset.

## Decision

Do not advance to return measurement from this workbook alone. A separately specified revision-event reconstruction must recover the prior stock as known at each release, check it against ALL available captures, and retain unresolved rows. Historical release/availability evidence remains separately required. No relabeling of the failed Wayback test or inventory/weather family; one prior killed family return trial remains counted.

The audit uses only already acquired public files. All compressed capture payload hashes, workbook/manifest hashes and source bindings verify. Captures are neither independent random observations nor proof about missing weeks. All comparison rows, including the mismatch, are retained. Prior data-gated CFTC, bondNAV, spin-off and natural-gas results were inspected to avoid treating old failed routes as new opportunities.
